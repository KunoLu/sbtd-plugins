# SBTD Workflow Onboard

Use this Skill to prepare a local Oh My Pi environment and initialize selected projects with the bundled SBTD workflow assets.

The managed runtime provides schema-validated plans, explicit confirmation classes, transactional writes, and postcondition checks for Skills, supported tools, MCP entries, and Trellis project initialization. Bootstrap work remains a separately confirmed Agent handoff; deterministic installation must not be reported as completed bootstrap work.
