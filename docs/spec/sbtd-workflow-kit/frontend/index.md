# sbtd-workflow-kit Frontend Guidelines

> Reshaped layer: this package has **no UI**. "Frontend" here means the **authored text artifacts**
> the generator produces and consumes: upstream AGENTS templates, Kit targets, overlays, and the
> Gherkin feature files that specify the transform's observable behavior. Pipeline mechanics and
> TypeScript conventions live in [../backend/](../backend/index.md).

---

## Overview

The package's "user interface" is Markdown and YAML read by developers and agents:

| Artifact | Path |
|---|---|
| Upstream AGENTS templates (input) | `vendor/sbtd-workflow-kit-upstream/sbtd-workflow-onboard/templates/agents/AGENTS.{global,project}.md` |
| Section classification (input) | `agents-section-map.yaml` (schemaVersion 2, 49 entries) |
| Kit target overlays (input) | `overlays/AGENTS.project-omp.md` |
| Rendered AGENTS targets (output) | `generated/AGENTS.{global,project-root,project-omp}.md` |
| Behavior specs | `features/agents-transformation.feature`, `features/agent-plugin-projection.feature` |

## Pre-Development Checklist

- [ ] You are editing an **input** (template in `vendor/` via `sync-upstream`, section map,
  overlay) — never a file under `generated/`, which is regenerated byte-exactly.
- [ ] A new or renamed AGENTS section is classified in `agents-section-map.yaml` (see
  [Template Authoring](./template-authoring.md)).
- [ ] The behavior change is specified in a `features/*.feature` Scenario and mirrored by a test
  (see [../backend/testing.md](../backend/testing.md)).

## Quality Check

- [ ] `pnpm --filter @kunolu/sbtd-workflow-kit generate` then `check-generated` pass.
- [ ] Omitted/replaced sections do not leak into any rendered target (enforced by
  `assertExcludedSectionsAbsent` — if it throws, fix the map/overlay, not the check).
- [ ] Authored text bound for `generated-omp/` contains no `codex` token (any case).

---

**Language**: Spec documentation is written in **English**; upstream templates, overlays, and
feature files keep their existing (mostly Chinese) language.
